# Paywall one-time modal (web only) Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Show a one-time "Semester Pro" pricing pitch (9.99/mo · 90/yr) on the web dashboard, once per browser/device, never again.

**Architecture:** One boolean on the existing persisted settings store (`semester.settings`) + one modal component. The dashboard renders the modal 1.2 s after hydration when the flag is false; every dismiss path sets the flag. No backend, no checkout — the modal is a pure pitch.

**Tech Stack:** Next.js 16 client component, zustand persist (already wired via `gatedJSONStorage`), existing `ui/Modal` primitive, existing i18n (`useT()`).

**No test framework exists in the repo** — each task verifies with `pnpm lint` and `pnpm build` plus a rendered-HTML check where cheap. Design doc: `docs/plans/2026-10-19-paywall-design.md`.

### Task 3: `PaywallModal` component

**Files:**
- Create: `src/components/paywall/PaywallModal.tsx`

**Step 1: Write the component** — exact file contents:

```tsx
"use client";

import { useEffect, useState } from "react";
import { Check } from "lucide-react";
import Modal from "@/components/ui/Modal";
import { useSettingsStore } from "@/lib/store/settings";
import { useT } from "@/lib/i18n";

/**
 * One-time Pro pitch for the web app. Nothing is gated — the only state is
 * settings.proPitchSeen: shown once per device ~1.2 s into the dashboard,
 * then never again on this browser.
 */
export default function PaywallModal() {
  const t = useT();
  const seen = useSettingsStore((s) => s.proPitchSeen);
  const setProPitchSeen = useSettingsStore((s) => s.setProPitchSeen);
  const [open, setOpen] = useState(false);

  useEffect(() => {
    if (seen) return;
    const timer = setTimeout(() => setOpen(true), 1200);
    return () => clearTimeout(timer);
  }, [seen]);

  const dismiss = () => {
    setOpen(false);
    setProPitchSeen();
  };

  return (
    <Modal open={open} onClose={dismiss} title="Semester Pro">
      <p className="-mb-2 text-sm text-ink-soft">
        {t("One price, everything unlocked.")}
      </p>
      <div className="mt-4 grid gap-3 sm:grid-cols-2">
        <div className="rounded-xl border border-line p-4">
          <p className="font-mono text-[10px] tracking-[0.14em] text-ink-soft uppercase">
            {t("Monthly")}
          </p>
          <p className="mt-2 font-display text-3xl font-semibold tracking-tight">
            9,99 €
            <span className="ml-1.5 font-mono text-xs font-normal text-ink-soft">
              {t("per month")}
            </span>
          </p>
          <p className="mt-1 font-mono text-[11px] text-ink-soft">{t("cancel anytime")}</p>
        </div>
        <div className="relative rounded-xl border border-accent bg-accent/[0.06] p-4">
          <span className="absolute -top-2.5 right-3 rounded-full bg-accent px-2 py-0.5 font-mono text-[10px] text-paper">
            {t("best value")}
          </span>
          <p className="font-mono text-[10px] tracking-[0.14em] text-ink-soft uppercase">
            {t("Yearly")}
          </p>
          <p className="mt-2 font-display text-3xl font-semibold tracking-tight">
            90 €
            <span className="ml-1.5 font-mono text-xs font-normal text-ink-soft">
              {t("per year")}
            </span>
          </p>
          <p className="mt-1 flex items-center gap-1 font-mono text-[11px] text-accent">
            <Check className="size-3" /> {t("save 25%")}
          </p>
        </div>
      </div>
      <div className="mt-5 flex flex-col gap-2 sm:flex-row-reverse">
        <button
          onClick={dismiss}
          className="flex-1 cursor-pointer rounded-lg bg-accent px-4 py-2.5 text-sm font-semibold text-paper transition-opacity hover:opacity-90"
        >
          {t("Got it")}
        </button>
        <button
          onClick={dismiss}
          className="flex-1 cursor-pointer rounded-lg border border-line px-4 py-2.5 text-sm font-medium transition-colors hover:bg-paper-deep"
        >
          {t("Continue free")}
        </button>
      </div>
    </Modal>
  );
}
```

Notes: `text-paper` on the accent badge assumes the theme pairing used by `isToday(day) ? "bg-accent text-paper"` in page.tsx — same convention. Two CTAs intentionally share one handler: any click (and backdrop/Escape/X via the Modal's `onClose={dismiss}`) marks seen once. `dismiss` fires even when the button that closes is the span CTA — `setProPitchSeen` is a plain set, idempotent.

New strings `"One price, everything unlocked."`, `"Monthly"`, `"Yearly"` get entries in Task 2's block:
- `"One price, everything unlocked."`: "Ein Preis, alles freigeschaltet."
- `"Monthly"`: "Monatlich"
- `"Yearly"`: "Jährlich"
(The single German-language price format `9,99 €` is display intent, not locale logic — one string, same in both languages.)
